# Group F Presentation Guide

## 1. Introduction
Introduce the examination results management problem and the proposed solution.

## 2. Users
Explain lecturer, reviewer, approver, student and administrator permissions.

## 3. Demonstration
1. Log in as lecturer.
2. Submit marks for the sample course.
3. Log in as reviewer.
4. Verify or return the submission.
5. Log in as approver.
6. Approve and publish the verified submission.
7. Log in as student.
8. Display published personal results.

## 4. Negative API tests
Demonstrate invalid credentials, invalid scores, duplicate submissions,
missing correction reason, role denial and out-of-order publication.

## 5. Technical explanation
Describe Express routes, MySQL relationships, JWT authentication,
validation, transactions and audit records.

## 6. Limitations
Explain that the prototype uses sample data and is not integrated with
official MUST systems or official grading policies.

## 7. Teamwork
Each member explains their actual contribution and GitHub pull request.
